# Agent and Controller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Execution status (2026-11-17):** checkbox ในไฟล์นี้ไม่เคยถูก tick และไม่ใช่สถานะล่าสุด — Task 1–5, 7–9 ฝั่ง software implement แล้ว, Task 6 credential/TLS/GUI และ Moonlight pairing พิสูจน์สดแล้ว, ส่วนที่เหลือเป็น hardware/live proof ดู `docs/superpowers/plans/STATUS-2026-11-17.md`

**Goal:** เชื่อมเว็บกับเครื่องเช่า Windows จริง ตั้งแต่ลงทะเบียน อนุมัติ เปิดเครื่อง จับคู่ Moonlight จนปิดเมื่อหมดเวลา และคืนสภาพรับผู้เช่าถัดไป

**Architecture:** Next.js เรียก Controller ผ่าน API บน loopback ที่ยืนยันตัวตน Controller เป็น C#/.NET Windows Service และเจ้าของฐานข้อมูลเครื่อง/lease แยกจาก auth เดิม Agent C#/.NET บนเครื่องลูก poll ผ่าน HTTPS และบังคับเวลาหมดอายุเอง

**Tech Stack:** Next.js 16.4.3/React 19.3.0 เดิม, .NET 10 (พบ SDK 10.0.302), ASP.NET Core, Microsoft.Data.Sqlite, Windows Service hosting, xUnit, Node test runner เดิม ใช้แพ็กเกจเวอร์ชันเข้ากันได้และ pin ตอน implementation

**Spec:** `docs/superpowers/specs/2026-10-29-agent-design.md` — ผู้ใช้อนุมัติแล้ว 2026-10-29

## Global Constraints

- เครื่องแม่รัน Next.js และบริการควบคุม C#/.NET Windows Service แยก process บนเครื่องเดียวกัน
- หมดเวลาสั่งปิด Windows ทันที ไม่มีแจ้งเตือน ไม่มีช่วงผ่อนผัน
- เครื่องใหม่ต้องรอแอดมินตรวจ ตั้งชื่อ ราคา และอนุมัติ
- ใช้ Reboot Restore Rx Pro คืนสภาพทุกครั้งที่บูต เครื่องอนุมัติแล้วไม่ต้องอนุมัติซ้ำ
- การแก้พอร์ตเป็น metadata เท่านั้น ไม่แก้ Sunshine หรือ Router จริง
- หนึ่ง allocation ต่อเครื่อง; ไม่คิดเวลาระหว่างบูต; preparing timeout 5 นาที
- Poll/heartbeat ทุก 5 วินาที; ขาด heartbeat 20 วินาทีเป็น unreachable ไม่ใช่ powered-off
- ราคาต่อชั่วโมงเป็นจำนวนเต็มสตางค์; เวลาจัดเก็บ UTC แสดง Asia/Bangkok
- ไม่ทำ Parsec, VNC, payment gateway หรือหักยอดเงินจริงในแผนนี้
- ก่อนเขียน Next.js อ่าน `node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/route.md`, `page.md` และคู่มือ fetching/caching ที่เกี่ยวข้องในแพ็กเกจนี้
- คำสั่งทดสอบปิดเครื่องทั้งหมดใช้ fake โดยปริยาย Hardware test ต้องเลือกเครื่องลูกทดลองอย่างชัดเจน ห้ามปิดเครื่องแม่หรือเครื่องที่รันการพัฒนา
