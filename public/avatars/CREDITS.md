# Bundled default avatars

12 Bottts avatars downloaded from DiceBear's 9.x HTTP API on 2026-10-29.

- Artwork: Bottts by Pablo Stanley, remixed by DiceBear.
- License: free for personal and commercial use.
- Style and license details: https://www.dicebear.com/styles/bottts/
- Source artwork: https://bottts.com/
- Download pattern: `https://api.dicebear.com/9.x/bottts/svg?seed=kamenraider-robot-01&backgroundColor=b6e3f4,c0aede,d1d4f9,ffd5dc,ffdfbf` (seeds 01–12).

The app serves these local SVG files directly. No request to DiceBear is made when a user visits the app.
